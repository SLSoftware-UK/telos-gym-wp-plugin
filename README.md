# TelosGym Schedule

WordPress plugin: embed a TelosGym studio's live class schedule via `[telos_schedule]` or the "TelosGym Schedule" block.

See `readme.txt` for the WordPress.org listing copy (the actual plugin description/FAQ/changelog).

## Development

```
npm install
npm run build
npx @wordpress/env start   # local WordPress at http://localhost:8888, admin at /wp-admin (admin/password)
```
